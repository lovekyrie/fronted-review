# Learning Journal: 2026-09-22

## Q1: this 绑定有没有优先级？

**Context**: `interview/jscore/basic/this.md`

**Key points**:

- 有。普通函数：`new` > 显式（`call`/`apply`/`bind`）> 隐式（`obj.fn()`）> 默认（独立调用）。
- 箭头函数不进这条链：没有自己的 `this`，先看是不是箭头函数。
- `new` 能压过 `bind`；箭头函数的 `this` 改不了，也不能 `new`。

**Details**: [../knowledge/javascript/this-binding-priority.md](../knowledge/javascript/this-binding-priority.md)
