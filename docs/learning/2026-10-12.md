# Learning Journal: 2026-10-12

## Q1: useCapture 为 true 是不是就不会再冒泡？

**Context**: `interview/jscore/basic/event-mechanism.md`

**Key points**:

- `true` 只把这个监听器登记到捕获阶段，事件仍会捕获、到达目标、再冒泡。
- 父节点的捕获回调在向下经过时执行，然后事件继续走向子节点。
- 截断传播用 `stopPropagation`。
