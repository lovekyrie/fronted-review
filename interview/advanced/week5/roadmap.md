# Week 5 TypeScript 进阶

## 主题

TypeScript 进阶：类型系统、泛型设计、工具类型、业务建模

## 核心目标

- 能熟练解释条件类型、映射类型、模板字面量类型
- 能用 `infer` 和泛型约束设计更稳的 API
- 把"会写 TS"提升成"会设计类型"
