## 阅读卡点

- 分片大小 2–10MB 之间常见，要能讲清“为什么不是 100MB 一片”
- 秒传依赖服务端已存在 hash 库；hash 计算用 Web Worker + spark-md5 分片累加
- 断点续传靠服务端返回“已上传的分片索引”，前端跳过已传
