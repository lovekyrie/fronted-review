### HR 常问 10 题框架

| 题 | 回答要点 |
|----|----------|
| 自我介绍 | 30s 定位 + 30s 核心经历 + 亮点 |
| 离职原因 | 正向表达（寻求成长/挑战），不说前公司坏话 |
| 职业规划 | 3 年技术深度 + 5 年技术广度或管理，和岗位一致 |
| 薪资预期 | 说范围不说死数，"根据岗位职级，期望 XX-YY" |
| 加班态度 | "项目需要时愿意投入，但更注重效率和结果" |
| 优缺点 | 优点带案例，缺点带改进措施 |
| 团队冲突 | 用事实说话，数据驱动，求同存异 |
| 最大成就 | 用 STAR，突出个人贡献 |
| 对公司了解 | 提前调研公司业务，说出匹配点 |
| 还有什么问 | 问团队技术栈 / 业务方向 / 成长路径 |

## 口述题

### 1. 1 分钟自我介绍

回答模板（技术版）：

> 面试官好，我是 XX，有 X 年前端开发经验，技术栈是 Vue 3 + TypeScript + Vite。上一段在 XX 公司，主导了电商首页性能优化和后台权限系统重构。性能优化那个项目，我把首页 LCP 从 4.2 秒降到 2.1 秒，同时建立了 Lighthouse CI 防止劣化。最近在系统学习前端工程化和测试体系，对 Vitest + Playwright 的分层测试有比较深入的实践。看到贵司 JD 对性能优化和工程化有要求，我觉得和我的经验匹配度很高。

### 2. 你为什么选择离开上家？

回答模板：

> 主要是寻求技术成长。上一家公司的业务趋于稳定，前端技术栈更新比较保守，我在那个环境下成长空间有限。我希望能到一个技术氛围更好、业务更有挑战的团队，接触更复杂的场景（比如大流量、微前端、跨端），让自己的技术深度和广度都能进一步提升。
>
> （注意：不说前公司坏话，不说人际关系问题，不说钱少。核心传递"我主动寻求成长"。）

## 5 分钟录音顺序

按这个顺序录，不要临场重新组织：

1. 1 分钟自我介绍（1 分钟）
2. 离职原因 + 职业规划（2 分钟）
3. 薪资预期 + 加班态度 + "你还有什么问题"（2 分钟）

录完后自查：

- 自我介绍是否在 1 分钟内完成。
- 离职原因是否正向表达。
- 薪资预期是否说的是范围。
- 反问环节是否问了有价值的问题。
