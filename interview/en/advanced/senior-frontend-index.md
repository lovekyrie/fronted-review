## Week priority

1. Engineering and the build pipeline
2. Deploy and delivery
3. Vue internals
4. React internals
5. Advanced TypeScript
6. Browser, performance, security
7. Testing and quality
8. Architecture questions and mock interviews

Optional: after the 8-week spine, use [AI Agent engineering](../ai-agent/) for `Tool -> MCP -> Prompt/Parser -> Memory -> RAG -> SSE -> LangGraph/multi-agent -> eval`.

## How to run it

- Default `10–12 hours` a week
- `1.5–2 hours` a day
- `6 days study + 1 day recap`
- Every day must produce text or code — no read-only days
- Prefer landing notes back in this repo
