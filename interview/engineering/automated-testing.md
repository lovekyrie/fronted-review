# 自动化测试：单测与 E2E

## 一、测试金字塔（简化版）

- 单元测试（最多）：快、定位精确。
- 集成测试：验证模块协作。
- E2E 测试（较少）：模拟真实用户路径。

## 二、单元测试（Jest / Vitest）

### 核心关注

- 纯函数逻辑、工具函数、状态管理、组件行为。
- 隔离依赖（mock 网络、时间、随机数）。

```ts
import { describe, it, expect } from 'vitest'
import { sum } from './sum'

describe('sum', () => {
  it('adds numbers', () => {
    expect(sum(1, 2)).toBe(3)
  })
})
```

## 三、E2E 测试（Cypress / Playwright）

### 核心关注

- 关键业务链路：登录、下单、支付、权限校验。
- 接近真实浏览器环境，发现联调问题。

## 四、覆盖率怎么回答

- 覆盖率不是越高越好，关键是**关键路径覆盖**。
- 常见指标：`statements`, `branches`, `functions`, `lines`。
- 建议设下限门槛（如 70%~80%）并针对核心模块更高要求。

## 五、面试回答模板

1. 先说测试分层策略。
2. 再说团队如何落地（CI 中跑哪些测试）。
3. 最后说收益（回归 bug 率下降、发布更稳）。
