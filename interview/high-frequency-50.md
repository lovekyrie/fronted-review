# 高频 50 题速记表（1 分钟回答模板）

使用方式：每题按「定义/原理 -> 场景 -> 坑点/权衡」三句结构回答，控制在 40~70 秒。

## A. JS 基础（1~10）

### 1. JS 数据类型有哪些？如何判断？
- 模板：JS 有基本类型和引用类型；`typeof` 适合基础判断，`Object.prototype.toString.call` 更准确。
- 场景：区分 `null`、数组、对象时用 `toString`。
- 坑点：`typeof null === 'object'`。

### 2. `this` 绑定规则是什么？
- 模板：默认绑定、隐式绑定、显式绑定、`new` 绑定，优先级是 `new` > 显式 > 隐式 > 默认。
- 场景：回调函数里 `this` 丢失常用箭头函数或 `bind`。
- 坑点：箭头函数没有自己的 `this`。

### 3. `new` 关键字做了什么？
- 模板：创建新对象、绑定原型、执行构造函数、返回对象。
- 场景：手写 `new` 可验证理解深度。
- 坑点：构造函数显式返回对象会覆盖默认返回值。

### 4. 原型链是什么？
- 模板：对象通过 `[[Prototype]]` 链接到原型对象，属性查找沿链向上。
- 场景：复用方法放在原型上节省内存。
- 坑点：原型链过长会影响查找性能与可维护性。

### 5. 闭包是什么？优缺点？
- 模板：函数持有外部作用域引用形成闭包，可做封装与状态持久化。
- 场景：防抖节流、私有变量。
- 坑点：长期持有大对象可能导致内存泄漏。

### 6. 深拷贝和浅拷贝区别？
- 模板：浅拷贝只复制第一层引用，深拷贝递归复制所有层级。
- 场景：状态管理中避免直接修改原对象。
- 坑点：`JSON.parse(JSON.stringify())` 会丢函数、`undefined`、`Date`。

### 7. `let` / `const` / `var` 区别？
- 模板：`let/const` 块级作用域，存在暂时性死区；`var` 函数作用域且变量提升。
- 场景：默认优先 `const`，需要重赋值再用 `let`。
- 坑点：`const` 保护的是引用地址，不是对象内容不可变。

### 8. 箭头函数和普通函数区别？
- 模板：箭头函数语法简洁且继承外层 `this`，不能 `new`，无 `arguments`。
- 场景：定时器回调中避免 `this` 丢失。
- 坑点：对象方法不建议盲目用箭头函数。

### 9. 防抖和节流区别？
- 模板：防抖是“最后一次触发后执行”，节流是“固定间隔执行”。
- 场景：输入搜索用防抖，滚动监听用节流。
- 坑点：要考虑首触发与尾触发策略。

### 10. 事件委托原理？
- 模板：利用事件冒泡把子元素事件统一绑定到父元素。
- 场景：动态列表项点击处理。
- 坑点：要用 `closest` 定位真实目标元素。

## B. 异步与事件循环（11~16）

### 11. Event Loop 是什么？
- 模板：JS 单线程运行，主线程执行栈清空后，从任务队列取任务执行。
- 场景：解释 `setTimeout` 和 `Promise.then` 顺序。
- 坑点：微任务优先于下一轮宏任务。

### 12. 宏任务和微任务有哪些？
- 模板：宏任务如 `setTimeout`、I/O；微任务如 `Promise.then`、`MutationObserver`。
- 场景：复杂异步链路要控制微任务过多导致 UI 饥饿。
- 坑点：连续微任务可能阻塞渲染。

### 13. Promise 状态与链式调用？
- 模板：`pending -> fulfilled/rejected` 不可逆，`then` 返回新 Promise 支持链式。
- 场景：串行异步流和错误统一处理。
- 坑点：漏写 `return` 会打断链式语义。

### 14. `async/await` 本质？
- 模板：`async` 返回 Promise，`await` 是语法糖让异步流程更像同步。
- 场景：提升可读性，配合 `try/catch` 处理异常。
- 坑点：串行 `await` 可能慢，可改并发 `Promise.all`。

### 15. `Promise.all` / `allSettled` 区别？
- 模板：`all` 任一失败整体失败，`allSettled` 收集所有结果不短路。
- 场景：强依赖任务用 `all`，容错汇总用 `allSettled`。
- 坑点：`all` 中长耗时任务失败后其余请求可能已发出。

### 16. 如何控制并发请求？
- 模板：用请求队列限制并发数，完成一个补一个。
- 场景：大文件分片上传、批量接口拉取。
- 坑点：要有重试、超时、取消策略。

## C. 浏览器与网络（17~24）

### 17. 从输入 URL 到页面展示发生了什么？
- 模板：DNS 解析 -> TCP/TLS 建连 -> HTTP 请求 -> 解析 HTML/CSS/JS -> 渲染。
- 场景：定位首屏慢可按链路逐段分析。
- 坑点：阻塞资源会延迟首次渲染。

### 18. 强缓存与协商缓存区别？
- 模板：强缓存命中直接本地返回；协商缓存需服务端确认是否 304。
- 场景：静态资源用强缓存 + hash，接口数据用协商缓存。
- 坑点：缓存策略和版本发布要联动。

### 19. HTTP 常见状态码怎么答？
- 模板：2xx 成功，3xx 重定向，4xx 客户端错误，5xx 服务端错误。
- 场景：重点说 `200/204/301/302/304/401/403/404/500`。
- 坑点：`401` 是未认证，`403` 是已认证但无权限。

### 20. HTTP1.1、2、3 主要差异？
- 模板：HTTP2 多路复用+头部压缩，HTTP3 基于 QUIC 降低队头阻塞。
- 场景：高并发资源请求场景 HTTP2/3 优势明显。
- 坑点：协议升级需要服务端/CDN 支持。

### 21. 为什么会跨域？如何解决？
- 模板：浏览器同源策略限制，常见方案是 CORS、反向代理、`postMessage`。
- 场景：前后端分离开发常用 dev proxy。
- 坑点：别把 JSONP 当通用方案，它只支持 GET。

### 22. 预检请求（OPTIONS）什么时候触发？
- 模板：非简单请求会触发预检，服务端需返回允许的源/方法/头。
- 场景：自定义头、PUT/DELETE 常见触发。
- 坑点：预检失败常是服务端 CORS 配置不全。

### 23. Cookie / localStorage / sessionStorage 区别？
- 模板：Cookie 可随请求发送且体积小；`localStorage` 持久；`sessionStorage` 会话级。
- 场景：登录态更常见用 HttpOnly Cookie 或 token 方案。
- 坑点：敏感信息不要裸存本地存储。

### 24. XSS 和 CSRF 如何防护？
- 模板：XSS 防注入和转义；CSRF 用 SameSite、CSRF Token、双重校验。
- 场景：富文本输入和表单接口是高风险点。
- 坑点：仅前端过滤不够，后端必须参与防护。

## D. 性能与监控（25~30）

### 25. Web Vitals 有哪些？
- 模板：FCP、LCP、CLS、INP（旧指标 FID）。
- 场景：优化前后必须看线上真实用户指标。
- 坑点：只看实验室数据不够，要结合 RUM。

### 26. 如何优化 LCP？
- 模板：优化首屏主资源：图片压缩/预加载、减少阻塞、SSR/SSG。
- 场景：首屏大图是 LCP 元素时收益最大。
- 坑点：只压缩 JS 但忽略首屏图片常见无效。

### 27. CLS 高怎么解决？
- 模板：为图片/广告位预留尺寸，避免异步插入挤压布局。
- 场景：骨架屏和懒加载区块需固定占位。
- 坑点：字体切换也可能引发布局抖动。

### 28. 首屏性能优化从哪里下手？
- 模板：先测量定位，再做资源优先级、代码分割、缓存与渲染优化。
- 场景：按“网络、CPU、渲染”三类定位瓶颈。
- 坑点：先优化后测量很容易做无效劳动。

### 29. 前端错误如何全量捕获？
- 模板：`onerror` + `unhandledrejection` + 框架错误边界 + 资源错误监听。
- 场景：监控 SDK 要统一采集、去重、采样、上报。
- 坑点：监控本身不能拖慢主业务。

### 30. SourceMap 还原堆栈原理？
- 模板：把压缩堆栈位置映射回源码行列号，前提是版本与 SourceMap 对齐。
- 场景：线上定位生产报错时非常关键。
- 坑点：SourceMap 泄露有安全风险，需权限隔离。

## E. 框架（31~36）

### 31. Vue 响应式核心原理？
- 模板：Vue3 基于 Proxy 做依赖收集与触发更新。
- 场景：精准追踪依赖，减少不必要更新。
- 坑点：解构后丢响应性是高频问题。

### 32. React 为什么快？
- 模板：通过 Fiber 可中断调度 + 最小化提交 + 组件化状态管理提升可维护性。
- 场景：大页面拆分更新粒度更细。
- 坑点：盲目 `memo` 可能得不偿失。

### 33. React Hook 使用规则？
- 模板：只在函数顶层调用，保证调用顺序稳定。
- 场景：自定义 Hook 抽离复用逻辑。
- 坑点：依赖数组遗漏导致闭包陷阱。

### 34. Vue/React diff 的共性与差异？
- 模板：都做同层比较与 key 辅助复用；实现细节和调度模型不同。
- 场景：列表渲染 key 稳定可减少无效重建。
- 坑点：用 index 作为 key 在重排时会出错。

### 35. 状态管理何时需要引入？
- 模板：跨层级共享、复杂派生状态、可追踪调试需求明显时引入。
- 场景：中后台权限、筛选条件、跨页缓存。
- 坑点：小项目过度状态管理会增加复杂度。

### 36. 路由鉴权怎么做？
- 模板：前置守卫判断登录态 + 动态路由权限 + 403 回退。
- 场景：后台管理系统常见按角色动态菜单。
- 坑点：前端鉴权是体验控制，不是安全边界。

## F. 工程化（37~42）

### 37. Webpack 和 Vite 区别？
- 模板：Webpack 偏 bundle 先构建，Vite 开发时基于 ESM 按需加载更快。
- 场景：中大型老项目偏 Webpack，现代新项目偏 Vite。
- 坑点：迁移时要评估插件生态与构建链兼容。

### 38. Loader 和 Plugin 区别？
- 模板：Loader 处理模块内容转换，Plugin 扩展构建生命周期能力。
- 场景：TS/CSS 转换用 Loader，打包分析/注入能力用 Plugin。
- 坑点：别把二者能力混为一谈。

### 39. Tree-shaking 生效条件？
- 模板：基于 ESM 静态分析 + 标记未引用导出 + 压缩删除死代码。
- 场景：工具函数库按需引入明显减包体。
- 坑点：副作用代码会阻碍摇树。

### 40. 为什么要做规范化工作流？
- 模板：ESLint + Prettier + Husky + lint-staged + commitlint 提升质量与协作效率。
- 场景：提交前就拦截低级错误，减少 CI 返工。
- 坑点：规则过严会拖慢效率，要逐步推进。

### 41. CI/CD 在前端的价值？
- 模板：自动测试、构建、发布，减少人工失误并提高交付频率。
- 场景：多环境发布和回滚流程标准化。
- 坑点：没有质量门禁的流水线价值有限。

### 42. 如何做前端测试分层？
- 模板：单测覆盖核心逻辑，E2E 覆盖关键业务路径。
- 场景：登录、支付、权限链路必须有 E2E。
- 坑点：追求 100% 覆盖率不现实，关键路径优先。

## G. 场景设计（43~47）

### 43. 大文件上传如何设计？
- 模板：分片上传 + 断点续传 + 秒传校验 + 服务端合并验 hash。
- 场景：上传大视频或数据包。
- 坑点：并发过高会放大失败率。

### 44. 海量列表如何优化？
- 模板：虚拟列表减少 DOM，时间分片减少长任务。
- 场景：万级日志/消息列表。
- 坑点：不定高列表要维护高度缓存与偏移修正。

### 45. 权限体系如何设计？
- 模板：登录态、角色、资源权限三层；前端做展示控制，后端做最终校验。
- 场景：路由、菜单、按钮、接口权限联动。
- 坑点：只做前端权限存在越权风险。

### 46. 如何设计监控 SDK？
- 模板：采集（错误/性能/行为）-> 缓冲队列 -> 上报（采样/重试）-> 平台分析。
- 场景：线上稳定性治理。
- 坑点：监控数据要脱敏合规。

### 47. 如何设计通用组件库？
- 模板：API 一致性、主题能力、文档体系、测试保障、版本治理。
- 场景：多业务线复用统一 UI 规范。
- 坑点：过度抽象会影响业务迭代速度。

## H. 前沿 + 项目 + HR（48~50）

### 48. SSR/SSG 什么时候选？
- 模板：SSR 适合强动态首屏与 SEO，SSG 适合内容稳定页面。
- 场景：营销页、内容页优先 SSG；个性化强页面偏 SSR。
- 坑点：要处理 hydration mismatch。

### 49. 如何讲一个项目亮点？
- 模板：用 STAR：背景、任务、行动、结果（必须量化）。
- 场景：性能治理、架构升级、稳定性提升都可讲。
- 坑点：只说“做了什么”不说“为什么和结果”会减分。

### 50. HR 问“为什么选择我们”怎么答？
- 模板：公司业务方向 + 岗位技术挑战 + 个人成长路径三点匹配。
- 场景：提前研究 JD、产品和团队技术栈。
- 坑点：避免空泛套话或只谈薪资。
