# 复杂交互：拖拽排序与富文本选区

## 一、拖拽排序

### 实现思路

1. 按下元素时记录起始位置与元素索引。
2. 移动过程中计算当前位置应插入到哪个索引。
3. 只在索引变化时更新数据，减少无效重排。
4. 抬起时落盘并触发后端持久化。

### 关键难点

- 滚动容器中的拖拽：要考虑容器滚动偏移。
- 占位元素：防止列表高度抖动。
- 大列表性能：只更新必要项，结合虚拟列表。

## 二、富文本编辑器：选区与光标

### 核心概念

- `Selection`：用户当前选区（可能跨节点）。
- `Range`：选区对应的起止边界对象。

### 常见操作

- 保存选区：执行工具栏操作前先缓存 `Range`。
- 恢复选区：点击加粗/插入链接后恢复光标位置。
- 结构修复：处理粘贴内容时做标签白名单过滤。

```ts
const selection = window.getSelection()
if (selection && selection.rangeCount > 0) {
  const range = selection.getRangeAt(0).cloneRange()
  // 这里缓存 range，工具栏动作后再 restore
}
```
